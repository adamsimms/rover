# As-submitted residency packets

Tracked archive of what was actually submitted to residency programs. **Draft while writing** may stay in `Sketchpad/residencies/` (scratch). **On submit**, promote a redacted as-submitted packet here so the record survives beyond one machine. Apply-wave status lives in the vault Residencies MOC and the public binder, not in Sketchpad.

Canonical concept: [conceptual-core.md](../../concept/conceptual-core.md). Process lessons: [application-craft.md](../application-craft.md). Binder index: [adaptation.md](../adaptation.md).

## Promote rule

| Stage | Where |
|-------|-------|
| Drafting | `Sketchpad/residencies/calls/<slug>*.md` (git-ignored) |
| Submit | Fill the form; note confirmation on the apply Issue |
| Promote | Copy as-submitted texts into `docs/residencies/submissions/<slug>/`; redact phone, street address, and anything still funder- or consent-restricted |
| After | Dual-write status to the vault Residencies MOC and the public binder. Sketchpad may keep scratch for the next call; it is not live status. Do not treat the tracked packet as a working draft. |

Do **not** paste full essays into GitHub Issues. Do **not** promote CV PDFs or portfolio binaries unless an Issue explicitly asks.

## Private boundary

Redact before promote: phone numbers, street addresses, exact ask amounts where a funder’s terms restrict discussion, consent-sensitive living-people detail. Public program fees and named funder *intent* (e.g. CCA + CALQ) are fine when they were on the submitted form. See [OPERATING-MODEL.md](../../OPERATING-MODEL.md).
